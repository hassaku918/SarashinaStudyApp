# Sarashina Study — 受験勉強用 AI Android アプリ

[Sarashina AI](https://sarashina.ai) の **無償ベータ API** を使った大学受験向け学習アシスタントです。

## 主な機能

- **ダークモード** — 設定から システム / ライト / ダーク を切替
- **PDF / 画像スキャン** — ML Kit 日本語 OCR
- **深い推論** — `sarashina3.2-mini-thinking` + `reasoning_effort: high`
- **会話記憶** — Room でローカル保存
- **受験特化プロンプト** — 段階的解説・家庭教師風

## セットアップ

1. [sarashina.ai](https://sarashina.ai) で Google ログイン → API Key 発行
2. `git clone https://github.com/hassaku918/SarashinaStudyApp.git`
3. Android Studio で開きビルド
4. 起動後、設定から API Key を保存（テーマも同じ画面）
